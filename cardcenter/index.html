Card Center

A collection manager for Magic: The Gathering cards. Scan a card, and it is in your collection.

Why

I play Magic. A collection quickly runs into thousands of cards, and listing them by hand, to trade them or build a deck, is slow and full of mistakes. Other collectors told me the same. Card Center turns that inventory into a scan.

What it will be

A free mobile app to scan cards, and a web dashboard to manage the collection. Today the API and the website work; the scanner is in progress; the mobile app is planned and not started.

How it is built

  • Scanner in C++ with OpenCV: edge detection and perspective correction, then Tesseract reads the card name. Card data comes from Scryfall.
  • API in ASP.NET Core over PostgreSQL.
  • Website in React and TypeScript with Vite. It replaced the Blazor dashboard I had first planned.
  • Four GitHub repositories in Gitflow, full CI/CD with GitHub Actions, decisions recorded as ADRs.
  • Deployed in containers on my Synology NAS.

Where it stands

In October 2026 the API reached v0.3.0 and the website v0.2.0. Next: finish the scanner, then the mobile app in Flutter.
