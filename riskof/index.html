Risk of Library

A fast wiki of Risk of Rain 2 items, because the official wiki is too slow to read in the middle of a run.

Visit riskof.gerios.fr

Why

In the game you need an item's effect in two seconds. The Fandom wiki is heavy and full of ads. I wanted one page with every icon and the numbers on hover.

What it does

  • Every item icon in one grid, folded by rarity.
  • Hover an icon: name, quote and effect, with the numbers in colour.
  • Instant search by name.
  • A switch for each expansion, to show or hide its items.
  • A protected admin page to edit items and upload icons.

How it is built

On purpose, without a framework or a build step: static HTML and vanilla JavaScript, a small PHP API that returns JSON, and MariaDB. It runs on my Synology NAS, behind a Cloudflare Tunnel.

Items are imported automatically: a script reads the Lua modules behind the Fandom wiki and fills the database.

Over the years

  • 2023: first version, a static page and a PHP API.
  • 2025: one request instead of one per tab, search, redesign.
  • 2026: automatic import from the wiki, then the admin page.
