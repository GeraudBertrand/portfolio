Pot2Colle

An audit of an existing website for a teacher, then the fixes: structure, performance, security. A seminar project in a large mixed team.

Read the recommendationsRead the competitor study

The request

A teacher wanted his website to work better. We had to find what was wrong, explain it to someone who is not a developer, recommend changes, and make them.

What we changed

  • Duplicated code reorganised into a Model-View-Controller structure.
  • A new MySQL schema for user accounts.
  • Lazy loading, and images moved to SVG and WebP.
  • Role-based authentication: teacher, parent, student.

What I learned

  • Explaining technical debt and MVC to a client who does not need the words, only the consequences.
  • Children's data on a school site: GDPR is not a footnote.
  • Coordinating code through Git with thirteen people, most of whom were not developers.
