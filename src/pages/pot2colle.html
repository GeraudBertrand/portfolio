Sujet d'analyse

Le Concept

Assister un professeur dans l'amélioration de son site web. Le projet vise à identifier les forces et faiblesses du site, proposer des recommandations concrètes et mettre en œuvre des optimisations pour améliorer l'expérience utilisateur.

Les Enjeux

Le projet a été réalisé dans le cadre d'un séminaire universitaire, avec pour objectif de fournir une analyse stratégique du site web du client. Les enjeux principaux étaient de comprendre les besoins, analyser l'existant, et formuler des recommandations claires pour améliorer la performance et l'accessibilité.

Résultats Techniques

  • Refonte MVC : passage d'un code redondant à une architecture structurée (Modèle-Vue-Contrôleur).
  • Ingénierie de données : création d'un MCD MySQL optimisé pour la gestion sécurisée des utilisateurs.
  • Optimisation Performance : intégration du Lazy Loading et passage aux formats SVG/WebP.
  • Sécurité : déploiement d'un système d'authentification à rôles granulaires (Prof/Parent/Élève).

Leçons Apprises

  • Médiation

    Vulgarisation de concepts techniques (MVC, Dette technique) pour un client non-expert.

  • Clean Code

    Application stricte du principe DRY pour garantir la maintenabilité future du projet.

  • Éthique

    Sensibilisation aux enjeux RGPD et protection des données mineures en milieu scolaire.

  • Agilité

    Coordination technique et synchronisation via Git dans une équipe multidisciplinaire.
