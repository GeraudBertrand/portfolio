Card Center

Un gestionnaire de collection de cartes Magic: The Gathering. On scanne une carte, elle est dans la collection.

Pourquoi

Je joue à Magic. Une collection atteint vite des milliers de cartes, et les lister à la main, pour les échanger ou construire un deck, est long et plein d'erreurs. D'autres collectionneurs m'ont dit la même chose. Card Center remplace cet inventaire par un scan.

Ce qu'il sera

Une application mobile gratuite pour scanner, et un tableau de bord web pour gérer la collection. Aujourd'hui l'API et le site fonctionnent ; le scanner est en cours ; l'application mobile est prévue, pas commencée.

Comment il est construit

  • Scanner en C++ avec OpenCV : détection des bords et correction de perspective, puis Tesseract lit le nom de la carte. Les données des cartes viennent de Scryfall.
  • API en ASP.NET Core sur PostgreSQL.
  • Site en React et TypeScript avec Vite. Il a remplacé le tableau de bord Blazor prévu au départ.
  • Quatre dépôts GitHub en Gitflow, CI/CD complète avec GitHub Actions, décisions consignées en ADR.
  • Déployé en conteneurs sur mon NAS Synology.

Où il en est

En octobre 2026, l'API est passée en v0.3.0 et le site en v0.2.0. Ensuite : finir le scanner, puis l'application mobile en Flutter.
